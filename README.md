# TY Spanish · Conversation Challenge

Juego proyectable de conversaciones guiadas creado para las clases de TY Spanish del Sr. Martín.

## Publicación en GitHub Pages

Sube todo el contenido de la carpeta `dist` a la raíz del repositorio. Después activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main / root**.

No necesita servidor, base de datos, cuentas ni claves. Los puntos solo existen durante la partida y se borran al iniciar una nueva.

## Contenido

- Partida 1: Conocer a alguien (20 rondas)
- Partida 2: Un día en el instituto (20 rondas)

Para crear temas nuevos, duplica un objeto dentro de `data/conversations.json` y conserva la misma estructura.
